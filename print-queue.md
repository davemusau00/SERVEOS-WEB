Clear obsolete terminal print jobs
The native POS now offers Clear obsolete print jobs… to an Admin. Select individual jobs or all displayed jobs (up to 50), enter a reason, review the uncertain-delivery warning and confirm cancellation.
Use this for obsolete commissioning/test jobs or receipt attempts which no longer need to print. If a customer still needs their receipt, keep the job or issue a reprint from receipt history using the working printer configuration. Existing Retry print uses the printer profile snapshotted when the job was created.
Cancellation is a durable CANCELLED state. It preserves the original receipt payload and transport error and writes the actor, timestamp, reason and previous job states to the immutable local audit. It does not confirm physical output, record hardware acceptance evidence, alter business data or add cloud outbox work.
The queue and final acceptance counter exclude cancelled jobs. SENDING jobs cannot be cancelled. A stale selection fails atomically so operators must refresh and review again. Initial sends claim SENDING before releasing the database lock to prevent a cancellation/send race. No SQLite schema migration is needed.
After installing the updated native build:
1. Sign in as Admin and open POS.
2. Select Clear obsolete print jobs, review the old jobs, enter the reason and confirm.
3. Return to Business Admin and refresh the acceptance status. Only unresolved jobs should remain in the count.
4. Close the active till through the normal close-day flow before final acceptance.
