# Report and business-document catalogue

**Status: foundation only.** This map describes the current PostgreSQL-backed projections and issued snapshots; it is not a claim that the full SERVEOS V2 document catalogue has shipped. Required outputs are from [`SERVEOS-V2.md` DEV-023–DEV-027](../SERVEOS-V2.md#dev-023-required-document-catalogue). Missing or incomplete sources must remain visibly incomplete, not be filled with estimates.

`apps/api/src/projection-access.mjs` is the current record-visibility policy. Many browser bootstrap projections are recent-history subsets (for example, documents, journals, tills, refunds, stock movements, and stock counts are capped at 1,000); a visible projection is not automatically a complete reporting dataset. No new report permission is introduced by this foundation slice.

## Close-day CSV foundation

The **Download verified CSV** action is available for a selected issued close-day report. It:

- verifies the snapshot SHA-256 using the same canonical JSON ordering as the document issuer;
- exports snapshot leaves as UTF-8 CSV with document number, document ID, snapshot hash, issue time, JSON-Pointer path, value, and value type;
- retains arrays, booleans, nulls, and numeric amounts without querying current records or re-running calculations;
- protects text fields from spreadsheet formula interpretation; and
- refuses unsupported document types, a changed snapshot, or values that cannot be represented safely.

This is an export of one immutable issued document, **not** a configurable report builder, financial-period CSV, or replacement for reconciliation. The reusable A4/thermal catalogue, multi-page quality fixtures, and PostgreSQL/browser report reconciliation remain follow-up work. Physical printer acceptance is separate.
