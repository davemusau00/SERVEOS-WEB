# Property and rooms

The property workspace covers room types, rooms, rate plans, services, reservations, stays, housekeeping state and guest folios. API commands validate room availability, reservation dates and the requested lifecycle transition.

Check in only after confirming the guest and reservation. Folio charges, deposits, payment and checkout update the server ledger. A room remains unavailable while an active maintenance state or reservation blocks it.

Use [customer credit](customer-credit.md) for customer account balances and [finance and assets](finance-assets.md) for assets and financial workflows.
