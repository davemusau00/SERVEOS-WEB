# Assets and maintenance

Section: Property
Roles: Admin, Manager, Maintenance
Permission: assets.view, assets.manage, maintenance.view, maintenance.manage
Screen: finance
Keywords: assets, maintenance, custody, work order

## Overview

The asset register tracks permanent asset identity, location, custody and lifecycle. Maintenance records work orders and parts.

## Procedure

1. Search by the permanent asset tag.
2. Record custody or a location transfer with a reason.
3. Open a maintenance work order and assign the work.
4. Record completion only after the work is verified.

## What ServOS handles

The API records asset events and work-order changes separately from stock movements.

## Common mistakes and correction

Do not use asset edits to erase a transfer or dispose of an item. Record its lifecycle action.
