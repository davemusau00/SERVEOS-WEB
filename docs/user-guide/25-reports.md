# Reports

Section: Finance
Roles: Admin, Manager, Accountant
Permission: reports.view
Screen: finance
Keywords: reports, totals, audit, activity

## Overview

Reports summarize API records for the selected date range and business scope.

## Procedure

1. Open Finance or Activity.
2. Select the report and date range.
3. Review filters, totals and source references.
4. Follow a source reference to the transaction or reconciliation that produced the value.

## What ServOS handles

The API filters report data using the current staff permissions.

## Common mistakes and correction

Reports reflect committed API records. A draft or queued command may not appear until its outcome is confirmed.
