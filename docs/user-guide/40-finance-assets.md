# Finance and assets

Section: Finance
Roles: Admin, Manager, Accountant
Permission: accounting.view, reports.view, assets.view
Screen: finance
Keywords: finance, journals, reports, fixed assets

## Overview

Finance reports and journals summarize committed API events. Asset records use their own lifecycle.

## Procedure

1. Select a business date or reporting period.
2. Review the source references behind each total.
3. Reconcile discrepancies using the relevant source workflow.
4. Review asset tags, custody and maintenance records separately from inventory stock.

## What ServOS handles

The API builds reports from committed records and restricts them by permission.

## Common mistakes and correction

Do not edit a journal total to force a report to balance. Correct the source transaction and regenerate the report.
