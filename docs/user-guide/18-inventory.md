# Inventory overview

Section: Inventory
Roles: Admin, Manager, Storekeeper
Permission: inventory.view
Screen: inventory
Keywords: stock, locations, reorder, barcode

## Overview

The Inventory workspace shows stock items, balances by location, reorder levels and recent movements.

## Procedure

1. Search by stock name, code or barcode.
2. Filter by stock state or location.
3. Open the stock item in Catalog to review its base unit, scan quantity and purchase packages.
4. Use Count, Receive, Transfer or Waste for quantity changes.

## What ServOS handles

The API validates units, balances, permissions and expected record versions for inventory commands.

## Common mistakes and correction

Do not edit a quantity on a master-data form. Record the reasoned inventory action so the movement history remains complete.
