# Rooms and reservations

Section: Property
Roles: Admin, Manager, Front Desk
Permission: rooms.view, rooms.manage, rooms.operate
Screen: rooms
Keywords: rooms, reservations, rate plan, availability

## Overview

The Rooms workspace shows room status, room types, rate plans and reservations.

## Procedure

1. Review the room and reservation dates.
2. Confirm the guest, room type and rate plan.
3. Save or update the reservation using the available action.
4. Use Front Desk for arrival, stay and checkout actions.

## What ServOS handles

The API checks availability and the requested room lifecycle transition.

## Common mistakes and correction

Do not promise a room that is blocked by an overlapping reservation or active maintenance state.
