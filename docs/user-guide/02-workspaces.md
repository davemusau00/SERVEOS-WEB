# Workspaces

Section: Getting Started
Roles: Admin, Manager, Staff
Permission: help.view
Screen: help
Keywords: navigation, workspaces, permissions

## Overview

The navigation lists workspaces available to your staff account.

## Procedure

1. Choose Home to see common tasks.
2. Choose a workspace such as POS, Inventory, Procurement, Rooms, Finance or Help.
3. Use search and filters within the workspace to find a record.
4. Return to Activity to review saved work and synchronization status.

## What ServOS handles

The API filters records and actions using your permissions.

## Common mistakes and correction

If a workspace or action is missing, ask an administrator to review your permissions. Do not use another staff member's login.
