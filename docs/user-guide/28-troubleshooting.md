# Troubleshooting

Section: Operations
Roles: Admin, Manager, Staff
Permission: help.view
Screen: help
Keywords: sign in, network, conflict, printer, troubleshooting

## Overview

Use the displayed error and Activity record to identify whether a request was rejected, queued or has an unknown outcome.

## Procedure

1. Confirm the browser is online and the API status is healthy.
2. Read the full operator message and note its command reference.
3. For a conflict, refresh the record and review the current balance before correcting it.
4. For an unknown result, recover the original command before repeating the action.
5. For printer uncertainty, check the paper and printer queue before retrying.

## What ServOS handles

The API preserves command outcomes and provides change history for recovery.

## Common mistakes and correction

Do not refresh by clearing site data or create a replacement transaction while the first outcome is unknown.
