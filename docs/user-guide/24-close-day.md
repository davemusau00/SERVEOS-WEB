# Close day

Section: Finance
Roles: Admin, Manager, Cashier
Permission: till.close, reports.view
Screen: finance
Keywords: close day, drawer, reconciliation, report

## Overview

Close-day reporting summarizes committed sales, payments, refunds and till activity for the selected business date.

## Procedure

1. Review open till sessions and unresolved payment outcomes.
2. Enter and confirm the actual drawer count.
3. Resolve required variances or source discrepancies.
4. Generate and review the close-day report.

## What ServOS handles

The API calculates the report from committed records and records the close-day command outcome.

## Common mistakes and correction

Do not force a close while a required reconciliation is unresolved. Correct the source event and regenerate the report.
